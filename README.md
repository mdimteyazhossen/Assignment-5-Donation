# Donation Bangladesh

A simple and responsive donation website where users can enter an amount to donate, and a confirmation modal will appear to confirm their donation. Built with HTML5, CSS, JavaScript, and Tailwind CSS for a modern and mobile-friendly experience.

## Features

- **Navbar**: A navigation bar for easy website navigation.
- **Footer**: A footer section with important links or information.
- **Donate Button**: A button to initiate the donation process.
- **Donation Input**: Users can input their desired donation amount.
- **Confirmation Modal**: After entering the donation amount, a modal appears for confirmation before submitting the donation.

## Technologies Used

- **HTML5**: For structuring the content.
- **CSS**: For custom styling.
- **JavaScript**: For functionality such as modal handling and form submission.
- **Tailwind CSS**: A utility-first CSS framework used for responsive and clean design.
